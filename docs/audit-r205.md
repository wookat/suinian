### 1.2 「取消敏感标记」慢网 pending 态（R204 遗留建议）→ **确认缺失，定级 P2-2**
方法：CDP `Network.emulateNetworkConditions latency≈2000ms` + console 包装 fetch 计数 PATCH。实测：
- 点击后卡片与菜单**无任何 loading/禁用反馈**（与源码一致：web/src/pages/timeline.tsx `handleToggleSensitive` 无 busy 态、catch 静默）；
- pending 窗口内菜单可再开且**文案 stale**、可继续点击；连续操作实发 **3 个 PATCH（同一 note id）**；
- 因请求乱序覆盖，**刷新后终态与用户最后一次操作意图不一致**（s1_4_final_state_mismatch_after_reload.png）；
- 失败/超时无 toast、无回滚提示。
定级理由：不丢数据（last-write-wins），但敏感/非敏感是安全语义开关——慢网下用户可能以为已加密而实际未加密（或反之），全程无感知，故从 R204 的 P3 建议升级为 **P2**。修复方向：切换期间禁用菜单项 + spinner，或乐观更新 + 失败回滚 toast。
证据：s1_4_pending_no_feedback.png / s1_4_stale_menu_during_pending.png / s1_4_final_state_mismatch_after_reload.png。
