## 8. 结论对模型状态（degraded）的依赖

- 本轮**所有**漏出（A1 / A2 / A3 / A5 / U3）都发生在「确定性闸门未触发 → 内容进模型上下文 → 模型生成」路径上：闸门是否触发由称谓词表 / 受守行判据 / 数据层标注决定，**与主模型状态无关**；回退模型只影响漏出的**形态**（是否原样复述、是否把 `桃🌸花🌸源🌸记` 还原成 `桃花源记`、Q01 是否算对）。换主模型后这些载体**仍进上下文**，漏出概率可能变、根因不变。
- 反向：R324 的成立项（带称谓取值占位、SSE 对齐、聚合出口 needle 0、预言机中性文案）都是确定性路径，也与模型无关。
- 自动标敏感是模型判定（分拣模型），**degraded 下是否更容易把车牌 / 会议号误标为敏感，本轮无对照**【未验证】；U1 的严重度评估以「本轮实况」为准。
- ask-eval 141/141、财务 36/36 在 degraded 下通过，说明回退模型对结构化召回题足够；忠实性 27/30 与 R323 同分，未见回退模型导致的额外退化。
