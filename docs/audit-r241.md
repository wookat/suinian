## 3. 新发现问题分级

### P2-1 聚合问法覆盖缺口：「的」字与英文 total expenses 不走精确聚合【生产实测】
- 「这个月总支出是多少」→ finance_aggregate 精确统计 PASS
- 「这个月**的**总支出是多少」→ `no_answer`「没找到相关笔记」（账号 a、c 两个账号复现）
- 「What are my total expenses this month?」→ `no_answer`（复跑 3 次均失败）；而「What is my total income this month?」「How much did I spend in total this month?」PASS
- 「这个月的总收入是多少」在账号 a 失败、在账号 c 由 RAG 兜底答对（碰巧仅 1 条收入笔记，非确定性路由）
- 结构性归因【源码检查】：`stripFinanceWording()` 剥词后残留「的」或英文功能词（What are my…），`isFinanceAggQuestion()` 的 `length < 2` 判定不成立 → 不走 finance_aggregate → 落入 RAG，而聚合类问题 RAG 无法命中单条笔记 → no_answer。`TOPIC_CONNECTIVE_SPLIT_EX_RE` 已把「的」列为可切分连接词，但仅在主题切分路径生效，聚合判定路径未覆盖。
- 影响：常见口语问法（带「的」）与英文复数 expenses 问法拿不到答案；不产生错误数字（fail-closed），故定 P2 不定 P1。

### P3-1 q66/q68 类限定聚合的主题词提取质量【生产实测】
- q66 题面「给猫花的钱合计有多少」：按设计 fail-closed（不做心算合计）符合预期，但提取的关键词为「猫的、猫的钱」（带「的」尾巴的碎片），导致本可命中的「买猫粮/带猫打疫苗」笔记无法通过关键词召回。q68 followup「那买东西一共用了多少钱」提取「那买东西」同样带指代残留。
- 归因：主题词提取未去除「的」尾缀与句首指代「那」；行为安全（无幻觉）但召回缺口固化。

### P3-2 「买书花了多少钱」子集查询无法命中书名记录【生产实测】
- 账号 c 记有「买了《平凡的世界》上中下三册 96 元」（已正确分拣为 expense ¥96），问「买书花了多少钱」→ 按关键词「买书」精确匹配无结果，fail-closed。属召回未命中（诚实拒答），非幻觉；与 P3-1 同根：关键词字面匹配无同义/上位词扩展。
