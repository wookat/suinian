## 标题

碎念：开源可自部署的 AI 收件箱——往微信里丢想法/链接/待办，AI 自动分拣、串线索、出周报（Cubox 难民可一键搬家）

## 正文

做了大半年笔记工具的「收集侧」，一直觉得市面上的产品有两个拧巴的地方：

1. 记录有摩擦：再快的 App 也要打开 App。最顺手的入口其实是微信——反正一直开着。
2. 记完就死了：flomo 靠自觉回顾，Cubox 是稍后读坟场（而且官宣 2027-05 停掉速记和文件功能）。

于是写了碎念（Suinian），MIT 开源，整套跑在你自己的 Cloudflare 账号里（Workers + D1 + R2，免费额度个人够用）：

- 什么都能丢：文字 / 链接 / 语音 / 图片 / 文件 / 密码。入口有微信 bot（可选）、Web/PWA、Android 分享面板、浏览器剪藏扩展、REST API、MCP。
- AI 自动分拣四类（想法/待办/收藏/资料）+ 自动标签 + 链接抓正文摘要，不用自己整理。
- 思考线索：散落数周的同题碎片自动聚成一条线索，能看到一个想法是怎么长出来的——这是我自己最离不开的功能。
- 每周一推「你最近在想什么」周报，每天有今日回顾把老笔记翻出来。
- 敏感内容（密码/卡号/key）识别后 AES-256-GCM 加密存储。
- MCP server 内置：Claude Desktop / Claude Code / Cursor / Codex 可直接读写你的笔记库。
- Cubox / flomo 一键搬家：导出文件直接上传，创建时间和标签全保留，AI 重新分拣串线索。

技术栈：Hono + Cloudflare Workers + D1 + R2 + Workers AI（嵌入用 bge-m3），前端 React 19 + Tailwind v4，AI 可用 Workers AI（零外部依赖）或任意 OpenAI 兼容 API。后端 300+ 测试用例。

- 在线体验（演示模式，无需注册）：https://suinian.zalize.com
- 仓库（含 3 分钟自部署指南）：https://github.com/wookat/suinian

自部署踩坑、功能吐槽、架构问题都欢迎聊。
