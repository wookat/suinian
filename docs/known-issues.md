# 碎念 Suinian · 已知问题清单（beta）

> 本页面向使用者。碎念目前是**小范围 beta**（邀请码 + 名额），下面列的是我们**已经知道、但尚未修完或原理上做不到**的边界。安全承诺原文见注册页 / 设置页「安全承诺」；每一句承诺的实测行为对照表见 [docs/decision-r320.md §6](./decision-r320.md)。

> 更新：R320（2026-09）。如果你在使用中遇到这里没写的问题，请在 [GitHub Issues](https://github.com/wookat/suinian/issues) 反馈。

## 1. 安全边界：请把「识别」当作辅助，不要当作保险

**我们不保证认得出每一种危险内容。** 连续四轮（R314–R318）独立盲测证明，靠判据识别口令 / 破坏命令这件事在「族外变体」上不会收敛（R319 盲测：直答层凭证 8/22、破坏命令 10/16 漏）。你的笔记实际上过三道闸门，它们的性质不同：

1. **自动标敏感（主闸门，模型判定）**：大多数口令形笔记入库时会被自动标为敏感（R319 实测 21/25），进不了问答。它是模型判定：**可能误标**（`pwd` 这类日常命令也被标过），也**可能漏标**（标签与取值分在两条笔记、无标签的取值）。
2. **结构边界（不依赖识别）**：
   - 跨多条笔记的聚合回答、推送、导出、工具接口**不整段逐字转写**你的笔记（连续 8 字以上的片段不会出现；**8 字以内的短串可能出现**，例如 `さくらふじ`、`# @ ! %` 这类短值；R320 起答案里的字母数字混合高熵短串与 12 位以上数字串也一律占位）。
   - 你问**某一条**自己的笔记时，原文只会连同它的笔记卡片一起出现。**R320 起直答层不再尝试区分「口令 / 破坏命令 / 普通命令备忘」**：凡是含命令 / 代码形态、口令密钥、长串编号 / 高熵短串、以及非书签形态地址（IP 字面 / 主机:端口 / user@host / 内网・本机・`.local` `.internal` 一类保留后缀地址 / 拼读・编码地址）的行，问答区一律不转写，只给一句概括（「一条含口令/密钥的记录」「一条命令/代码备忘」等）+ 占位 + 引用角标，点开角标指向的卡片看原文。判据只决定占位文案和警示强度，不决定原文能不能进问答区（错分只影响措辞）。
   - 问「我的口令是不是 X」这类带候选值的核对问题，以及对含口令 / 命令 / 长串编号内容的任何**是非问**（「第一位是大写吗」「是不是 Q 开头」），问答区**不确认也不否认**（对对的、错的、半对的候选值给同一句话、同一组卡片），请点开卡片自己核对。
3. **判据（只管措辞与折叠强度）**：口令折叠 / 破坏命令高警示 / 日常命令展示，这些卡片层的分类仍由判据决定，**仍会错分**。

判据**没认出**、你也**没标敏感**的内容，在卡片里不折叠、不提醒；在直答里，只要它是纯散文（无命令 / 高熵串 / 非书签地址形态）就原样出现；**普通书签链接（协议头 + 公网域名 + 路径，无端口、无用户名）照常直答**（书签问链接是产品核心价值，R274/R302 决策）。内网 / 本机地址（10.x / 192.168.x / localhost / `.internal` 等）**与公网地址同样占位**：卡片层对它们不折叠（折叠管的是能否被公网取回执行），但直答层按结构面不区分公私网。本轮中途曾在生产浏览器实测到「内网 Grafana 地址 `http://10.0.3.7:3000/…`」直答原样，那是漏出（已在同轮第五次部署补上，见 decision-r320 §1.2 / §6.5）。

已知识别不到 / 识别不稳的形态（卡片层会原样展示、不提醒；直答层自 R320 起按上面的结构边界占位，不再依赖这张表）：

| 类别 | 形态 | 状态 |
|---|---|---|
| 口令 | 缩写 / 同形 / 错别字标签（`pw` `密马`）、未列入的语言标签、无标签取值（只写一串字符）、金融凭证（卡号 / CVV / 助记词分条写）、口述 / 算式 / 编码取值（「2 的 10 次方加 47」「Kilo Victor 九…」）、非拉丁数字系统、假名 / 西里尔口令 | 卡片层：**不折叠、不提醒**（R319 盲测 8/22 族外）。直答层：R320 本地盲测 22+13+18+12 条凭证载体逐字漏出 0；算式 / 拼读得出的短取值走「凭证断言拒答」（无卡片直达，指向时间流） |
| 破坏命令 | 中 / 日 / 韩 / 英**自然语言**的破坏意图（「把主库整个下掉」「wipe the whole production database」）、PowerShell / 文件载荷（`.bat` / `.ps1` 内容）、未列出的平台 CLI | 卡片层：**不警示**。直答层：命令形态（含未见过的 CLI）一律占位；**纯散文的破坏意图不占位、原样出现**（R319 盲测 6/29 条属此类，是有意为之：它不是可粘贴执行的东西，散文语义识别正是我们不再当安全边界的那件事） |
| 定时任务 | `crontab -r` | 只按「日常命令」展示，不单独高警示（保持既有行为） |
| 卡片折叠 | 同行 CJK 括号前缀（`《清缓存》rm -rf /srv/cache/*`）可能遮蔽数据面折叠 / 警示 | 问答层仍会警示；卡片层未修 |
| 检索串扰 | 同账号多条口令笔记时，问 A 的问题答案可能带出 B 所在笔记的标题 / 值 | 未修（P2） |
| 「相近记录」 | 相近记录列表会把**未识别**的危险笔记整条标题带出 | 未修（P2） |

**建议**：真正的口令 / 密钥请打开「标为敏感」（端到端加密，问答区只显示「（加密的敏感笔记）」），不要依赖自动识别。

**R320 的代价**（如实报告）：你问自己的一条日常命令备忘（`kubectl get pods`、`git push origin main`）时，问答区不再直接给命令，而是「一条命令/代码备忘：…点开引用的笔记卡片查看原文」+ 角标，多点一次。本地 307 条善意直答语料中被改动的从 22 条（7.2%）变为 77 条（25.1%），增量全部是命令备忘 / 高熵识别符 / 路径形态；纯散文 / 记账 / 待办不受影响。

## 2. 复制提醒的覆盖范围

对**口令折叠卡**（credential）、**破坏命令警示卡**（destructive）与**标为「敏感」的卡片**，以下复制路径都会先弹提醒核对（R319 真实浏览器 18/18 路径实测成立）：

- 卡片菜单「复制」
- 展开后选中文字 Ctrl+C / 右键复制
- 整页全选（Ctrl+A）后复制
- **编辑框内**选中复制 / 剪切（R318 新增）
- **敏感卡展开后**的四条路径（R318 新增）
- 问答答案区**选中 / 右键**复制（答案区没有独立的「复制答案」按钮）——提醒看的是选中内容：答案里只有占位句 / 概括、没有受守原文时**不弹提醒**（R320 生产浏览器实测：口令卡的占位答案复制不提醒，剪贴板里只有占位句；破坏命令卡的概括答案有提醒）

**日常命令备忘卡（code，正文上方有一行提示、但不折叠）不在上面的范围内**，它的复制行为是：

- 卡片菜单「复制」：弹确认框
- 展开后选中 Ctrl+C / 右键复制：**直接复制**，事后给一行「已复制…」提示
- 整页全选复制、编辑框内复制 / 剪切：**不提醒**（剪切会直接移除文字）

这是设计如此（日常命令备忘需要频繁复制），但也意味着：如果一条破坏命令被判据错分成日常命令，它就只有 code 卡的复制行为。

**不提醒**的情形：

- 判据没认出、也没标敏感的普通笔记（例如一段没被认出的口令）——这是「不保证识别」的直接后果。
- 真机触摸长按选区复制：**未验证**（R319 的 CDP 模拟触摸没能进入原生选区菜单）。
- 浏览器 / 系统级的截图、OCR、无障碍朗读等非剪贴板通道。
- 移动端第三方输入法自带的剪贴板同步。

提醒是「先确认再复制」，确认后剪贴板里就是原文；提醒本身不是拦截。

## 5. 不在承诺范围内的事

- 我们不做内容审核，不会替你判断笔记内容是否合法或合适。
- 你自己复制 / 导出 / 执行的内容，责任在你——提醒只是提醒。
- beta 期间数据结构可能迁移，可能需要你重新登录；请定期用「导出」保留自己的副本，不要把碎念当作唯一副本。
