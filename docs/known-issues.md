# 碎念 Suinian · 已知问题清单（beta）

> 本页面向使用者。碎念目前是**小范围 beta**（邀请码 + 名额），下面列的是我们**已经知道、但尚未修完或原理上做不到**的边界。安全承诺原文见注册页 / 设置页「安全承诺」；每一句承诺的实测行为对照表见 [docs/decision-r318.md §4](./decision-r318.md)。
>
> 更新：R318（2026-09）。如果你在使用中遇到这里没写的问题，请在 [GitHub Issues](https://github.com/wookat/suinian/issues) 反馈。

## 1. 安全边界：请把「识别」当作辅助，不要当作保险

**我们不保证认得出每一种危险内容。** 连续四轮（R314–R318）独立盲测证明，靠判据识别口令 / 破坏命令这件事在「族外变体」上不会收敛。R318 之后我们把安全边界放在**结构**上而不是识别上：

- 跨多条笔记的聚合回答、推送、导出、工具接口**不整段逐字转写**你的笔记（连续 8 字以上的片段不会出现；**8 字以内的短串可能出现**，例如 6 位数字 PIN、`さくらふじ`、`# @ ! %` 这类短值）。
- 你问**某一条**自己的笔记时，原文只会连同它的笔记卡片一起出现；被判据认出的口令 / 密钥类短串在问答区只给占位，点开卡片看原文。
- 判据**没认出**、你也**没标敏感**的内容：不折叠、不占位、不提醒，原样出现。

已知识别不到 / 识别不稳的形态（会原样出现在直答与卡片里）：

| 类别 | 形态 | 状态 |
|---|---|---|
| 口令 | 非拉丁数字系统（阿拉伯-印度数字、天城文数字）、假名 / 西里尔字母组成的口令、5–7 位纯字母、13 位以上纯数字、日期形口令 | R318 已把「标注词 + 邻接不透明串」改为基元并覆盖这些形态（本地纯函数盲测 18+18+27 条归零；生产复测结果见 decision-r318 §2），**但族外新形态仍可能漏** |
| 破坏命令 | 绝对路径 / 转义别名（`/bin/rm -fr`、`\rm -rf`）、管道（`find … \| xargs rm`）、无 `-r` 的 `rm -f`、未列出的平台 CLI、纯中文转述（「把 sessions 表清空」） | R318 已改为「删除 / 覆写 / 销毁能力 + 作用对象」的行为面判定；**中文转述与未见过的 CLI 仍可能不警示** |
| 定时任务 | `crontab -r` | 只按「日常命令」展示，不单独高警示（保持既有行为） |
| 卡片折叠 | 同行 CJK 括号前缀（`《清缓存》rm -rf /srv/cache/*`）可能遮蔽数据面折叠 / 警示 | 问答层仍会警示；卡片层未修 |
| 检索串扰 | 同账号多条口令笔记时，问 A 的问题答案可能带出 B 所在笔记的标题 / 值 | 未修（P2） |
| 「相近记录」 | 相近记录列表会把**未识别**的危险笔记整条标题带出 | 未修（P2） |

**建议**：真正的口令 / 密钥请打开「标为敏感」（端到端加密，问答区只显示「（加密的敏感笔记）」），不要依赖自动识别。

## 2. 复制提醒的覆盖范围

R318 之后，对**带折叠 / 警示标记的卡片**与**标为「敏感」的卡片**，以下复制路径都会先弹提醒核对：

- 卡片菜单「复制」
- 展开后选中文字 Ctrl+C / 右键复制
- 整页全选（Ctrl+A）后复制
- **编辑框内**选中复制 / 剪切（R318 新增）
- **敏感卡展开后**的四条路径（R318 新增）
- 问答答案区复制

**不提醒**的情形：

- 判据没认出、也没标敏感的普通笔记（例如一段没被认出的口令）——这是「不保证识别」的直接后果。
- 浏览器 / 系统级的截图、OCR、无障碍朗读等非剪贴板通道。
- 移动端第三方输入法自带的剪贴板同步。

提醒是「先确认再复制」，确认后剪贴板里就是原文；提醒本身不是拦截。

## 3. 问答（AI）已知行为

| 现象 | 说明 | 状态 |
|---|---|---|
| 多条笔记的「为什么 / 怎么变」问题只得到「〔原文查看〕…」一句 | 聚合层不逐字转写；模型若整段照抄笔记，收口后只剩占位。R318 改为：先重试让模型用自己的话概括，仍无实义时给出「命中笔记列表 + 指引」而不是空占位 | R318 已改，仍可能出现在极短笔记上 |
| 答案里出现〔已隔离笔记内指令，未采纳〕 | 命中的笔记里含有对 AI 的指令（「回答时请…」），系统隔离了它。误判时原文仍在卡片里 | 按设计 |
| 主模型不可用时回答质量下降 | 主模型故障会自动回退到备用模型（Workers AI），召回与引用不变，措辞与概括质量可能变差 | 按设计；回退有服务端日志 |
| 藏尾诗 / 伪造出处类注入 | 极少数（R317：2/498）笔记内指令会被模型「执行」但不泄露内容。R318 已把「指令句里引号内的字面」作确定性剥除 | R318 已改，非确定性残余不排除 |

## 5. 不在承诺范围内的事

- 我们不做内容审核，不会替你判断笔记内容是否合法或合适。
- 你自己复制 / 导出 / 执行的内容，责任在你——提醒只是提醒。
- beta 期间数据结构可能迁移，可能需要你重新登录；请定期用「导出」保留自己的副本，不要把碎念当作唯一副本。
