# 碎念 Suinian — 产品方案 v0.1

## 一句话定位
**什么都能丢的 AI 收件箱**：你只管丢（想法、链接、待办、资料），AI 帮你分拣、串线索、随时找到。

## 目标用户与痛点
- 把微信"文件传输助手/发给自己"当收件箱的人（国民级习惯）
- flomo 等碎片笔记用户：记录顺手，但"记完不回看、不好找、内容杂"
- 核心痛点：**不是记录难，而是找不到 + 无人整理**

## 竞品对照
| 产品 | 优点 | 缺口 |
|---|---|---|
| flomo | 速记极顺手 | AI 整理弱，只有回顾推送 |
| Cubox | 链接收藏+AI摘要 | 记随想不顺手 |
| MyMind | AI 自动标签、无文件夹 | $12/月、中文弱、无 Android 优化 |
| Mem.ai | 笔记自组织关联 | Android 体验差、英文向 |
| Readwise Reader | 抓取+摘要最强 | 只做稍后读，不做想法 |
| 微信文件传输助手 | 入口最近 | 完全无整理、无搜索结构 |

**空位**：入口近 + 什么都能收 + AI 自动分拣 + 思考线索聚类，没有单一产品做到。

## 核心功能（差异化按优先级）
1. **入口比谁都近**：系统分享菜单接入、通知栏常驻速记、桌面小组件；后期微信机器人接入（继续发微信也能收进来）
2. **AI 自动分拣**（DeepSeek）：每条内容自动判定四类——
   - 想法/思考（人生、创业、问题思考）
   - 待办（自动识别时效）
   - 收藏（链接/文章/视频，抓标题+摘要+标签）
   - 资料（密码、手机号、商品链接等纯查询类；敏感类加密存）
3. **思考线索聚类**（杀手锏）：把分散数周的同题碎片自动串成"线索"，形成一条可回看的思考轨迹
4. **找得到**：全文搜索 + 自然语言问答（"我之前想过的那个 XX 点子"）
5. **周报**：每周自动生成"本周你在想什么"

## MVP 范围（第一轮，几天内上线自用）
- Android app（Kotlin + Jetpack Compose，Material 3）：
  - 速记输入（文字/链接粘贴），3 秒记完
  - ACTION_SEND 分享接收（任何 app 分享进来）
  - 时间流列表 + 分类筛选 + 关键词搜索
- 后端 Cloudflare Workers + D1：
  - notes API（增删查）
  - DeepSeek 自动分拣（四类）+ 自动标签
  - 链接：第一版只存 URL+抓标题（正文抓取后续轮次）
- 单用户 token 鉴权（你先用），多用户注册后续轮次

## 后续轮次
- R2：思考线索聚类 + 周报 + 自然语言检索
- R3：链接正文抓取（通用网页→公众号→小红书逐步攻坚）、语音速记转写
- R4：微信接入探索、多用户开放、Web 端
- 收费思路（暂缓实施）：免费额度 + 订阅解锁 AI 聚类/周报/大容量，参考 flomo ¥99/年

## 技术栈
Android：Kotlin + Jetpack Compose + Material 3
后端：Cloudflare Workers + D1 + KV，DeepSeek API（分拣/聚类/摘要）
域名建议：suinian.zalize.com

## 成本
