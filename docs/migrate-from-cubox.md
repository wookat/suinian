# 从 Cubox / flomo 迁移到碎念

> Cubox 已官宣将于 **2027 年 5 月停止「速记」与「文件」功能**——依赖 Cubox 随手记碎念的用户需要在窗口期内找到新家。碎念开源免费、可自部署，什么都能收（文字/链接/语音/图片/文件/密码），AI 自动分拣打标签、把碎片串成思考线索，每周还有周报。三步即可把 Cubox / flomo 的全部数据搬过来，**原创建时间与标签全部保留**。

## 为什么搬到碎念

| | Cubox | flomo | 碎念 |
|---|---|---|---|
| 随手速记 | ⚠️ 2027-05 停止 | ✅ | ✅ 微信 / Web / Android / API |
| AI 自动分类打标签 | ❌ | ❌（自己打标签） | ✅ 想法/待办/收藏/资料自动分拣 |
| 思考线索聚类 | ❌ | ⚠️ 仅回顾提醒 | ✅ 同主题碎片自动串成线索 |
| 每日回顾 / 周报 | ❌ | ⚠️ 每日回顾 | ✅ 每日回顾 + AI 周报 |
| 敏感内容加密 | ❌ | ❌ | ✅ AES-256-GCM |
| 开源可自部署 | ❌ | ❌ | ✅ MIT，数据在你自己的 Cloudflare 账号 |
| 价格 | 订阅制 | 免费+PRO | ✅ 免费 |

## 第一步：从旧工具导出

### Cubox

1. 打开 Cubox 网页版或客户端，选中要导出的收藏（或整个文件夹）。
2. 「共享/导出」→ 选择 **CSV**（推荐，信息最全）；书签 HTML 或 txt 也支持。
3. 保存导出文件到本地。

### flomo

1. flomo 网页版 → 设置 → 账号详情 → **导出所有数据（HTML）**。
2. 解压得到的压缩包，找到其中的 HTML 文件（如 `index.html`）。

> 其他工具？只要能导出 Markdown 或纯文本，也能导入（按 `---` 分隔线 / 标题 / 空行拆条）。

## 第二步：导入碎念

1. 打开 [suinian.zalize.com](https://suinian.zalize.com)（或你自部署的地址），注册/登录。
2. 进入 **设置页 →「导入数据」**：选择来源（Cubox / flomo / Markdown / 纯文本）→ 选择文件 → 上传。
3. 导入完成会显示统计：共解析多少条、成功多少、跳过重复多少。

也可以用 API 批量导：

```bash
curl -X POST https://suinian-api.zalize.com/api/import \
  -H "Authorization: Bearer <你的 token>" \
  -F source=cubox -F file=@cubox-export.csv
```

单文件最大 20MB；重复导入同一文件会自动跳过已存在的条目，放心多试。

## 第三步：验收与善后

- **时间线检查**：首页时间流按原创建时间归位，翻到历史日期抽查几条。
- **标签保留**：导出文件里的标签（含 flomo 的 `#tag` 与 Cubox 的标签列）会保留，并与 AI 建议的标签合并。
- **后台整理**：AI 分拣 / 线索聚类 / 知识图谱在导入后台陆续完成，几分钟到几小时不等（视数量）。
- **每日回顾**：迁移完成后，首页每天会出现「今日回顾」——那年今日 / 上月今日的老笔记配上 AI 一句话点评，老数据立刻活起来。

## 常见问题

- **图片会导入吗？** flomo 压缩包里的图片暂不导入，正文文字全部保留。
- **导错来源了怎么办？** 解析器会提示「未能解析出笔记」，不会写入脏数据；确认来源与文件格式匹配后重试。
- **数据安全吗？** 自部署时数据完全在你自己的 Cloudflare 账号；托管版支持随时全量导出（JSON / Markdown）与一键注销删除全部数据。

更多解析细节见 [docs/import.md](import.md)；自部署见 [docs/self-host.md](self-host.md)。
