## 九、新发现问题详述

### P2-1：绝对年月（`2026年5月`）不进时间窗聚合【生产实测，3/3 复现】

```
Q: 2026年5月我花了多少？      → 「没找到相关笔记。换个说法…」×3
Q: 今年5月我花了多少？        → 「今年5月共记录 1 笔支出…支出 ¥300」×3（同一账号同一数据）
```

同一时间窗、同一数据，只因写法从「今年X月」变成「2026年X月」就整体拒答。【源码检查】`ask.ts` 的 `parseTimeRange` 有 `(今年|去年)\s*(\d{1,2}|[一二三四五六七八九十]{1,2})\s*月` 分支，但没有四位绝对年份分支。影响：用户写完整年月是很自然的问法，且拒答而非降级到语义召回，属可感知的召回缺口。

### P2-2：历史时间窗 + 动宾/裸列举拒答【生产实测，3/3 复现】

```
Q: 去年下半年有哪些记录？      → 正确列举 3 条（电影 50 / 三体 68 / 剧本杀 128）×3
Q: 去年下半年我买了什么？      → 拒答 ×3
Q: 去年下半年分别是哪几笔？    → 拒答 ×3
```

时间过滤本身是对的（对照句证明数据可召回），缺的是「动宾式主题枚举」与「无前文的裸列举」在历史时间窗下的路由。注意 §1.1 的裸列举追问在**有财务聚合前文**时正常——说明 R248 修的是「追问」路径，「无前文 + 历史窗」这条路径仍未覆盖。

### P2-3：双主题并列查询只答其中一个，措辞仍称「精确统计」【生产实测，3/3 复现】

```
Q: 团队聚餐和团建各花了多少？
A: 按关键词「团队聚餐、团建各」精确匹配…共 1 笔支出：¥300（团队聚餐）
   实际数据：团队聚餐 ¥300 + 团建 ¥260
```

关键词切分把「团建各」当成一个词（`和` 未作为并列连接词切分，`各` 未剥离），漏掉团建 ¥260。危害在于**答案不完整却带「精确统计」措辞**，用户难以察觉缺口——比直接拒答更容易误导。

### P3-1：绝对年月枚举的时间标签丢年份【生产实测，3/3 复现】

```
Q: 2026年3月的笔记有哪些？
A: 「年3月你一共记了 1 条笔记：…」   ← 标签应为「2026年3月」
```

过滤结果正确，仅展示标签把四位年份吃掉（与 P2-1 同源：绝对年份未被时间解析识别，只剩「年3月」参与 display）。纯展示问题，故 P3。

### P3-2：品类语义查询无召回【生产实测】

`和吃喝有关的支出有哪些？` → 拒答，而账号内有「午饭 26 元」「买咖啡 35 元」「团队聚餐 300 元」。属品类/上位词语义扩展缺失（`吃喝` → 餐饮类）。当前 fail-closed 拒答是安全的，故 P3。

### P3-3：待办 checkbox 无 accessible name【生产实测，axe】

时间流待办项 checkbox 缺少可访问名，axe critical `label` violation ×1（`axe-r249.json`，同页 31 项 pass、heading-order 已清零）。

### P3-4：遗留 QA 空壳账号（见 §8）

另附一条观察（不单列问题）：给一张 8×8 纯色合成 PNG 做图片入库时，视觉描述输出了「2022年12月30日」之类无意义列表。属对无语义图片的模型输出噪声，真实照片路径本轮 UI 走查未复现异常，仅记录。
