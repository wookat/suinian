## 0. 结论

### NO-GO

**不能给真实用户用。** 阻断项是一条在**生产在线态**（非降级、非本地桩）可稳定复现的安全缺口：

> 只要远端地址不是纯 IPv4 字面（域名、子域、DoH URL、八进制/十六进制编码、IPv4-mapped IPv6、逐字空格域名、比喻化域名），且执行语义与地址不在同一行或经过模型改写/翻译，出口闭合面不收口，**危险地址 + 执行动作原样出现在最终答案里**。

生产 12 载体 × 2 问法 = 24 次真实问答：**15 次泄漏（62.5%）**，其中在线态（无降级）也泄漏。这正是 R298 §自报第 3 条自己标注为「推断」的那条缝——本轮把它变成了【实测确证】。

Day1 UX 主链路（注册/首屏/恢复码/写入/问答/编辑/设置/注销、长文总结不跳号、未来记账不并入当期、375px、Lighthouse、axe）本轮**全部通过**，R297 的 4 个 Day1 blocker 中的 ①③④在生产主链路取得正向证据。所以差的确实不是 40 件，而是**安全侧还差 1 件硬的（出口闭合覆盖面）+ 3 件软的（verbatim 长文回声、误伤率、口径如实告知）**。

## 3. B 面：SSE「15/20 无增量」的严重度判断

独立抓包 22 次（`qa-r299/prod-sse.mjs` → `prod-sse.json`，真实生产、真实召回、非缓存路径）：

| 指标 | 本轮独立测量 | R298 自报 |
|---|---|---|
| 有 delta | **21/22 (95.5%)** | 5/20 (25%) |
| 无 delta | 1/22 | 15/20 |
| `sse_held` 归因 | `dangling_citation:1` | dangling_citation / unsourced_negation |
| 首 delta p50 | **2690ms** | 3078ms |
| 首 delta p90 | 3737ms | 4114ms |
| done 恒 1 行 | 22/22 ✔ | ✔ |
| 先泄后收 | 0 ✔ | ✔ |

**严重度判定：非退化，但未达标（P1，不阻断发布）。**

- 「15/20 无增量」在独立样本中**不可复现**（1/22）。【推断】R298 那 20 次很可能集中在同一批易触发 `dangling_citation` 的问法上，属样本偏差而非闸门过严。

- **真正未达标的是首 delta 时延**：p50 2.69s ≫ 目标 1.5s，R278–R292 的「真流式」体验目标仍未兑现。分段数据（§6）显示瓶颈在 `dirext`(0.35–0.76s) + `conaud`(0.31–0.50s) + `gen`(1.5–2.6s) 的串行段，而非闸门扣留。
