## 7. 若要 GO，最低条件（审查意见，非实施指令）

1. 预言机中和触发改为**与句式无关**：只要召回集合命中守卫行（口令 / 长串 / 命令），任何「问属性 / 问真假 / 要变形输出」的请求都走中性文案；不能依赖句尾「吗」。

3. 回退 / 相近记录列表不得转写未标敏感笔记正文（只给标题或占位）。
4. 数字类取值：带口令 / 门禁 / 卡号 / 编号标签的 4–11 位数字、以及拆段可拼回的 ≥12 位数字进入守卫。
5. 修复纯占位答案复制误触；E08 隔离文案带角标；破坏命令卡默认态与 curl 卡统一。
6. known-issues §1 / §2 按 §6 逐句改写到与实测一致（书签 / 是非问 / 相近记录 / 复制），改完再跑一遍本报告 §3.3 / §4.4 的复现集。
