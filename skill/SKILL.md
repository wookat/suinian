# 碎念 Suinian — 什么都能丢的 AI 收件箱

## 一句话定位

你只管往微信里丢，AI 帮你分拣、串线索、随时找到 —— 并且有**独立产品界面**（Web 时间流/线索/周报视图），不止是 agent 工作区里的 markdown。

## 何时触发

- 用户发来任何想记录的碎片：一句想法、一个待办、一条链接、一张图、一段语音、一个文件、一条敏感资料（密码/账号）
- 用户以 `?` 或 `？` 开头提问，或表达想找回/回顾以前记过的东西
- 用户想看"我最近在想什么"（周报/线索）

## 前置配置（安装后一次性）

需要两个环境变量（用户在 openclaw 配置或 shell 中设置）：

| 变量 | 说明 |
|---|---|
| `SUINIAN_API_URL` | 碎念后端地址（自部署 Workers 地址，或托管版地址） |
| `SUINIAN_TOKEN` | 后端 Bearer token（Web 端设置页生成） |

未配置时：提示用户先完成配置，给出自部署文档链接（仓库 `skill/README.md`）。

## 行为规范

### 1. 记录（默认动作）

用户发送的任何非提问内容都视为要记录的碎片：

1. 规整 payload：`{source:"wechat", raw_type: text|link|image|voice|file, content, url?, attachments?}`
   - 文本里含 URL 且基本是纯链接 → `raw_type=link` 并带 `url`
   - 图片/语音/文件 → 下载媒体，小文件（≤8MB）base64 内联进 `attachments`
2. `POST {SUINIAN_API_URL}/api/ingest/wechat`，Header `Authorization: Bearer {SUINIAN_TOKEN}`
3. 把后端返回的 `reply` 确认文案原样回复用户（如「已存：想法 #创业 #AI」）
4. 后端会异步完成：AI 四类分拣、自动标签、链接抓取摘要、敏感信息加密、思考线索归并 —— skill 侧无需等待

### 2. 问答检索

`?`/`？` 开头的消息：

1. 去掉前缀得到问题
2. `POST {SUINIAN_API_URL}/api/ask`，body `{source:"wechat", question, wechat_user_id}`
3. 回复 `answer`（后端已附引用笔记）

### 3. 出错处理

- 后端 401/403 → 提示检查 `SUINIAN_TOKEN`
- 网络失败 → 告知稍后自动重试，不丢消息
- 一律用简短中文回复，不要长篇解释

## 与「记一下 just-note-ai」的差异（为什么选碎念）

| 能力 | just-note | 碎念 |
|---|---|---|
| 微信零摩擦输入 | ✅ | ✅ |
| AI 自动分类/标签 | ✅（9 类，存 markdown） | ✅（4 类，存独立后端 D1） |
| 链接抓取正文+摘要 | ❌ | ✅ |
| 思考线索聚类（跨周碎片串成线） | ❌ | ✅ |
| 独立产品界面（时间流/线索/周报视图） | ❌（只有 agent 工作区文件） | ✅ Web PWA |
| 自然语言问答检索 | 部分 | ✅（向量+关键词召回） |
| 脱离 OpenClaw 使用 | ❌ | ✅（Web/Android/API 均可入口） |

## 使用示例

```
用户：这个产品可以做成"什么都能丢的收件箱"，AI 自动分拣
碎念：已存：想法 #产品 #AI收件箱

用户：https://mp.weixin.qq.com/s/xxxx
碎念：已存：收藏 #AI #Agent（已抓取摘要：本文讲了…）

用户：记得下周三给服务器续费
碎念：已存：待办（下周三）#服务器

用户：?我最近关于创业都想了些什么
碎念：最近 3 周你有 7 条相关碎片，主线是「AI 收件箱产品」……（附引用）
```
